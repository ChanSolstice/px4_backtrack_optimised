# 当前版本返航飞行测试清单

## 1. 目的与适用版本

本清单用于验证 `fix/backtrack-control-safety` 分支完成优先修复后的返航行为，重点确认：

- 速度前馈是否真正生效；
- 正常飞行是否还会反复进入 Rejoin；
- 返航机头是否沿实际返航方向；
- 轨迹结束时是否存在异常 setpoint；
- 未到终点时是否会提前进入降落；
- POSCTL/AUTO.LAND 是否按飞控实际模式闭环切换。

代码基线：`53870ef`。其中 5 项代码修复为：

| 修复 | 提交 |
| --- | --- |
| 速度前馈 mask | `b3168b0` |
| 返航切线 yaw | `02be87d` |
| 降落悬停目标空窗 | `ff33eeb` |
| 降落模式闭环重试 | `981d223` |
| 终点位置验收 | `bb9f863` |

测试时必须填写实际分支和提交哈希；若代码发生变化，应重新执行地面检查和 SITL，不沿用之前结论。

## 2. 测试原则与放飞顺序

按照“先验证最小闭环，再增加轨迹复杂度和故障条件”的顺序执行：

```text
编译和单元测试
  -> 地面/SITL消息检查
  -> SITL完整流程
  -> 实机短直线
  -> 实机曲线航向
  -> 可选的受控Rejoin
  -> 降落闭环
```

任一阶段出现 P0 失败，停止后续测试，保留日志并分析；不要通过放宽阈值掩盖问题。

以下项目首轮只在 SITL 或系留环境执行，不在自由飞行中直接注入：

- 关闭 MAVROS、阻断 odom 或 RC 数据；
- 拒绝 `/mavros/set_mode` 请求；
- 长时间阻挡无人机使其无法到达终点；
- 强制触发 waypoint fallback 或非法轨迹配置；
- 人工推拉正在 OFFBOARD 飞行的无人机。

## 5. P0 修复回归清单

### FT-01：PositionTarget mask 与速度前馈

阶段：地面/SITL，之后在短直线实飞复核。

- [ ] CH7 触发后进入 `ReturnActive`。
- [ ] 正常轨迹 setpoint 的 `type_mask` 为十六进制 `0x01C0`，即十进制 `448`。
- [ ] `IGNORE_VX/VY/VZ` 未置位。
- [ ] `IGNORE_AFX/AFY/AFZ` 已置位。
- [ ] 轨迹运动段 `velocity.x/y/z` 与轨迹方向一致，且不应始终为零。
- [ ] Rejoin 时 mask 同样为 `0x01C0`，回拉速度不被屏蔽。
- [ ] setpoint 发布没有超过 `0.5 s` 的中断。

通过标准：mask 和字段意图完全一致；正常轨迹速度前馈可见；没有持续发布默认零目标。

### FT-02：名义飞行不再反复 Rejoin

阶段：SITL和实机短直线。

- [ ] 飞出一条无遮挡直线，再长按 CH7 返航。
- [ ] 全程记录 `ReturnActive`/`ReturnRejoin` 状态和位置误差。
- [ ] 名义无扰动返航不应进入 `ReturnRejoin`。
- [ ] 不出现历史日志中的约 2～2.4 秒周期性状态切换。
- [ ] 实际位置不会持续落后 setpoint 并逐步接近 `0.5 m`。
- [ ] 飞行速度连续，无明显“走—停—走”节奏。

失败标准：10 秒内出现两次及以上 `ReturnActive -> ReturnRejoin -> ReturnActive` 循环，直接判定失败并停止增加轨迹复杂度。

### FT-03：返航航向沿路径切线

阶段：先离线/SITL，再实机。

- [ ] 直线去程保持任意机头方向，触发返航后机头转向实际返航方向。
- [ ] 直线返航不继续保持去程 yaw，也不是简单依据触发 yaw 飞行。
- [ ] L 型或缓弯路径中，机头随返航路径逐渐转向。
- [ ] 水平速度明显非零时，比较：

  ```text
  yaw_direction = atan2(v_y, v_x)
  yaw_error = wrapToPi(yaw_setpoint - yaw_direction)
  ```

- [ ] 直线稳定段的 setpoint yaw 与 `yaw_direction` 基本一致。
- [ ] 曲线段允许受 `yaw_rate_max=0.6 rad/s` 限制，但不得长期侧飞或反向飞行。
- [ ] 终点水平速度接近零时，yaw 保持最近有效切线方向，不跳到零或触发时 yaw。
- [ ] 实际机头能跟随 yaw setpoint；实际跟踪误差门限在放飞前填写：`________ °`。

建议把“实际 yaw 跟踪误差”和“setpoint yaw 对切线误差”分开记录，避免把 PX4 姿态控制误差与返航规划错误混为一谈。

### FT-04：ReturnActive 到 LandingHover 无异常目标

阶段：SITL和实机正常返航。

- [ ] 记录轨迹完成前后至少 2 秒的每帧 setpoint。
- [ ] 状态从 `ReturnActive` 进入 `LandingHover` 的同一周期仍有合法 hold setpoint。
- [ ] hold 位置等于转换时飞机当前位置附近。
- [ ] 不出现位置 `(0,0,0)`、yaw `0`、`type_mask=0` 的单帧目标。
- [ ] 转换时飞机没有突然向地图原点加速、侧倾或转头。

通过标准：转换前后目标位置连续，LandingHover 保持当前位置约 5 秒。

### FT-05：终点位置验收

阶段：阻挡场景只在 SITL；实机只做正常到点验证。

- [ ] SITL 中让轨迹时间先结束，但保持飞机距离返航终点大于 `0.2 m`。
- [ ] 此时状态仍为 `ReturnActive` 或按误差进入 `ReturnRejoin`，不得进入 `LandingHover`。
- [ ] 飞机进入终点 `0.2 m` 范围后才允许进入 `LandingHover`。
- [ ] 实机正常返航中，记录进入 `LandingHover` 瞬间的实际终点距离。
- [ ] 实机终点距离不大于 `rejoin_success_dist_m`。

通过标准：时间结束只是必要条件，实际终点距离满足要求后才开始降落流程。

### FT-06：降落模式闭环与重试

阶段：正常路径可实飞；拒绝/失败注入只在 SITL。

- [ ] `LandingHover` 持续约 5 秒后进入 `LandingTransition`。
- [ ] 若飞控仍为 `OFFBOARD`，节点请求 `POSCTL`。
- [ ] 飞控确认退出 `OFFBOARD` 前，节点继续发布当前位置 hold setpoint。
- [ ] POSCTL 请求失败时约每 1 秒重试，不提前进入只请求 AUTO.LAND 的阶段。
- [ ] 飞控实际退出 `OFFBOARD` 后，节点请求 `AUTO.LAND`。
- [ ] AUTO.LAND 未被接受时约每 1 秒重试。
- [ ] `/mavros/state.mode` 确认 `AUTO.LAND` 后，返航节点停止 setpoint 和模式请求。
- [ ] 最终 DISARM，飞机无横向跳动。

注意：当前实现中 AUTO.LAND 接管后，内部状态会显示 `Recording`，直到 DISARM 后进入 `IdleDisarmed`。这是已知状态语义，不应误判为重新开始返航；但必须确认此期间没有 setpoint 或 OFFBOARD 请求。

## 6. 建议的分阶段实飞用例

### FL-01：短直线基础返航（首飞必做）

- [ ] 空旷区域、保守高度和短距离，去程约 5～10 m。
- [ ] 进入 `Recording` 后平稳直线飞行。
- [ ] 在稳定悬停时长按 CH7。
- [ ] 确认 `ReturnPreOffboard -> ReturnActive` 和飞控进入 OFFBOARD。
- [ ] 检查 mask、速度前馈、航向、setpoint 频率和 Rejoin 次数。
- [ ] 检查终点到达、5 秒悬停及 AUTO.LAND。

只有 FL-01 完全通过，才进入曲线测试。

### FL-02：与触发 yaw 不同的直线返航

- [ ] 去程结束后主动把机头转到与返航方向不同的安全方向。
- [ ] 触发返航。
- [ ] 确认返航 yaw 转向路径切线，而不是保持触发时 yaw。
- [ ] 检查转向过程平滑，水平运动未出现明显停顿。

### FL-03：L 型与缓 S 型返航

- [ ] 先做单个 L 型弯，再做缓 S 型路径。
- [ ] 检查轨迹没有明显越出安全区域。
- [ ] 检查弯道 yaw 连续、yaw-rate 不超过配置意图。
- [ ] 检查弯道速度变化与曲率一致，无异常的局部速度谷。
- [ ] 检查弯道后不触发周期性 Rejoin。

### FL-04：受控 Rejoin（前述用例通过后可选）

- [ ] 优先在 SITL 完成。
- [ ] 实机如需执行，应先通过 CH7 暂停并切到 POSCTL，再由飞手小范围移动，禁止直接推拉 OFFBOARD 飞机。
- [ ] 偏离超过 `0.5 m` 后恢复返航。
- [ ] 偏差持续超过 `0.25 s` 后进入 `ReturnRejoin`。
- [ ] Rejoin 目标保持冻结，回拉速度不超过 `0.3 m/s`。
- [ ] 进入 `0.2 m` 且持续 `0.10 s` 后恢复 `ReturnActive`。
- [ ] 恢复后不再次快速触发 Rejoin。

## 7. 修复后继续观察但不预设失败的项目

以下项目需要数据验证，不应在首轮发现轻微现象后立即扩大设计：

- [ ] 切线 yaw 输入后，CSV 中是否仍存在不合理的速度谷。
- [ ] 20 Hz timer 是否存在明显周期抖动或长间隔。
- [ ] 强风下是否仍出现反复 Rejoin。
- [ ] waypoint fallback 是否实际被触发；若未触发，不为它增加额外实飞故障注入。
- [ ] `CORRIDOR_EXCEEDED` 是否出现，以及实际任务是否要求把它视为硬失败。
- [ ] odom 或 MAVROS state 是否出现失鲜；当前节点没有完整健康监控，测试人员必须额外观察。

## 8. 立即中止条件

出现任意一项，立即人工接管并结束当前测试：

- setpoint 突然跳向地图原点或明显远离返航路径；
- 名义飞行反复进入 Rejoin，尤其出现稳定周期；
- 机头与飞行方向长期相差约 90° 或 180°；
- `/mavros/setpoint_raw/local` 明显中断或持续低于预期频率；
- 实际位置误差持续扩大，Rejoin 没有降低误差；
- 飞控意外退出 OFFBOARD，且节点仍按正常返航推进；
- odom、MAVROS state、RC 或定位数据停止更新；
- LandingTransition 停止 setpoint 后，飞控仍停留在 OFFBOARD；
- AUTO.LAND 请求后没有模式确认且不再重试；
- 电池、定位、地理围栏、遥控链路或现场安全条件异常。

## 10. 整体通过条件

本版本进入后续扩大范围测试前，必须同时满足：

- [ ] `type_mask=0x01C0`，速度前馈有效；
- [ ] 短直线名义返航无周期性 Rejoin；
- [ ] 直线和曲线返航 yaw 沿路径方向；
- [ ] ReturnActive/LandingHover 转换无原点或零 mask 目标；
- [ ] 未进入终点 `0.2 m` 范围时不会开始降落；
- [ ] POSCTL/AUTO.LAND 根据实际模式确认并可重试；
- [ ] 全程 setpoint 连续、模式可控、人工接管有效；
- [ ] 日志、rosbag、ULog 和 CSV 均已保存，可复盘上述结论。

不得仅以“最终飞回并落地”作为通过标准。
