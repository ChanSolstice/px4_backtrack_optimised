# 返航程序C++实现任务清单

## 项目概述

基于DDD架构实现ROS1 Noetic + MAVROS + PX4的返航程序，使用trajectory_core库进行轨迹生成。

### 阶段1: Domain层 - 数据结构和枚举 (1项)

- [ ] **T1.1** 在state_machine.hpp中定义核心数据结构
  - `enum class State`: 所有状态枚举
  - `enum class Event`: 事件枚举
  - `struct StateData`: 状态数据（锁定位置、计数器等）
  - `enum class ModeRequest`: 模式切换请求（None/OFFBOARD/POSCTL/AUTO_LAND）
  - `struct SetpointTarget`: setpoint 领域对象（position/velocity/yaw/yaw_rate/optional acc + type_mask + coordinate_frame）
  - `struct Vec3`: 简单三维向量（或使用Eigen::Vector3d）

### 阶段2: Domain层 - RecordingBuffer (1项)

- [ ] **T2.1** 实现RecordingBuffer类
  - **头文件** (recording_buffer.hpp):
    - `struct RecordPoint { Vec3 position; double yaw; double timestamp; }`
    - `void reset()`: 清空缓存
    - `void addPoint(...)`: 添加录制点（含节流逻辑 <=10Hz）
    - `size_t size()`: 获取点数
    - `std::vector<RecordPoint> getPoints()`: 获取录制点序列
  - **源文件** (recording_buffer.cpp):
    - 实现节流逻辑（记录上次录制时间）
    - 保存原始时间参考（first_odom_stamp），确保录制时间轴单调递增（用于质量检查/调试）

---

### 阶段3: Domain层 - TriggerEvaluator (1项)

- [ ] **T3.1** 实现TriggerEvaluator类
  - **头文件** (trigger_evaluator.hpp):
    - 配置参数结构体
    - `void updateRC(channels)`: 更新RC通道数据
    - `void updateLastRcMsgTime(double t_now)`: 更新“最近一次收到 /mavros/rc/in 的时间”（由 RCSubscriber 调用）
    - `void updateNow(double t_now)`: 更新当前时间（由 20Hz tick 或专用 timer 调用，用于 RC 丢失判定）
    - `bool checkCh7LongPress()`: 检测通道7长按
    - `bool checkCh7PressEvent()`: 检测通道7按下事件
    - `bool checkCh18Failsafe()`: 检测通道18故障确认
    - `bool checkRCLoss()`: 检测RC消息丢失（基于 `now - last_rc_msg_time`，不能依赖 RC 回调触发）
  - **源文件** (trigger_evaluator.cpp):
    - 实现按钮状态机（未按下/按下/长按）
    - 持续确认逻辑（ch18_confirm_s）
    - RC丢失检测（timeout + debounce，基于 timer/tick 驱动；即使完全收不到 `/mavros/rc/in` 也能触发）

### 阶段4: Domain层 - TrajectorySession (1项)

- [ ] **T4.1** 实现TrajectorySession类
  - **头文件** (trajectory_session.hpp):
    - `std::unique_ptr<trajectory_core::Trajectory> traj`: 轨迹对象
    - `double t_progress`: 当前进度时间
    - `double t_start_walltime`: 开始时的wall time
    - `double last_generate_cost_ms`: 最近一次生成轨迹耗时（debug/验收用）
    - `void reset()`: 重置会话
    - `bool generate(waypoints, config)`: 生成轨迹
    - `TrajectoryState evaluate(current_time)`: 评估当前状态
    - `bool isFinished()`: 是否完成
  - **源文件** (trajectory_session.cpp):
    - 集成trajectory_core::TrajectoryGenerator
    - 轨迹输入构造：位置/yaw 逆序；timestamp 重建为单调递增（例如 `t_new[i] = i * (1.0 / record_max_hz)`）
    - 记录轨迹生成耗时（`std::chrono`），并在生成完成后输出 INFO 日志（用于验收点记录与 debug）
    - 时间轴推进逻辑
    - 错误处理和退化模式

## 关键技术要点提醒

### 1. 坐标系处理
- 输入输出均使用ENU
- 发布PositionTarget时使用FRAME_LOCAL_NED，直接填ENU值（不在本节点内做坐标转换）

### 2. 时间轴管理
- 录制时间戳：相对时间（从0开始）
- 轨迹生成：使用逆序+重建单调时间轴
- 执行进度：t_progress基于wall time推进

### 3. Setpoint发布要求
- 必须20Hz稳定发布
- 轨迹生成期间持续发布固定点setpoint
- Ch18HoverWait期间持续发布
- 不能中断

### 4. 状态机关键点
- AUTO.LAND全局优先
- 点数检查在触发时完成
- Ch18倒计时不依赖OFFBOARD进入
- 暂停时冻结t_progress

### 5. 退化模式
- 轨迹生成失败时：保持固定点悬停并输出错误日志（不切换到其它 setpoint 话题；本项目只发布 `/mavros/setpoint_raw/local`）
