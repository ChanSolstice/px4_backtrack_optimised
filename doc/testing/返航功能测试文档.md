# 返航功能测试文档

## 1. 文档目的

本文档用于验证 `px4_backtrack_optimised` 当前 C++ 版本的返航功能是否符合实现预期，重点覆盖以下行为：

- 飞行周期复位与延时录制
- `CH7` 长按触发返航
- 直线分段飞行场景下的返航稳定性
- 返航过程中的暂停与恢复
- `CH18` 故障确认与固定点等待返航
- RC 消息丢失触发返航
- 录制点数不足时降级为降落
- 偏离轨迹后的 rejoin
- 返航结束后的降落过渡
- `AUTO.LAND` 优先级让步
- 已修复缺陷的回归验证

本文档面向联调、地面验收、SITL 验证和实飞前检查，不替代单元测试。

## 2. 测试范围

### 2.1 本次覆盖

- 返航主流程
- 典型飞行轨迹场景验证（直线、直角弯、S 型、随机曲线）
- 触发条件与阈值语义
- 状态机迁移
- 模式切换请求
- setpoint 发布行为
- RC 丢失状态发布
- 调试输出辅助验证
- 历史缺陷回归验证

## 7. 测试前准备

### 7.1 环境准备

- 确认节点能够正常启动，无参数缺失报错。
- 确认 `/mavros/state`、`/Odometry_px4`、`/mavros/rc/in` 正常更新。

- 如需测试失控状态，使用`tmux`来运行脚本，保证断连不会终断脚本运行，使用方式[参考下文](#73-tmux使用方式)

## 8. 判定原则

每条用例必须同时满足以下至少两类证据，才判定通过：

- 状态机状态符合预期
- 模式请求或飞控模式变化符合预期
- setpoint 发布行为符合预期
- 日志明确记录触发源或状态变更
- debug 轨迹或 CSV 能佐证执行路径

禁止仅凭“肉眼看起来像在返航”作为通过依据。
