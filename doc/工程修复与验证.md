# 返航工程修复与验证

本文件统一维护本轮返航模块结论、实现和验收。算法库的设计依据见 `../../trajectory_core/doc/工程审核与集成交接.md`（跨仓库相对路径从本文件所在目录解析）。运行边界：多旋翼、RK3588、速度小于 1 m/s、录制少于 1 h；期望原路偏离小于 0.3 m，硬上限 0.5 m，无在线避障。

低电量 `feat/low-battery-rth` 已合入 `dev`（b3db1c2）；本轮分支 `fix/return-engineering-contracts`。每项修复独立提交，未推送。

## 问题与实施记录

- APP-01：所有轨迹生成失败统一尝试原始录制点的航点返航；包括配置错误和过密几何。没有可用路径或录制点未达业务最小数量时仍执行既有降落流程。配置错误保留日志，降级不能隐藏配置问题。测试覆盖错误配置可降级、无空间路径仍降落。
- APP-02：仅删除同方向共线点，保留每个非共线原始顶点，沿每条原始连接线细分到 0.3 m；不跨拐角。默认到点半径 0.05 m，切换前要求三维速度 ≤0.10 m/s 和下一段航向误差 ≤15°。位置+yaw 模式下由 PX4 控制原地 yaw 速度。覆盖短直角、未停稳、未对准、无效输入。
- APP-03：取消从头 restart 接口；暂停和恢复均保留当前剩余航点索引，不重建路径，不回到录制末端。恢复仍先固定当前位置，并由 APP-02 的停稳/航向门槛控制继续执行。
- APP-04：待修复，连续且导数一致的参考进度。
- APP-05：待修复，原始录制折线的三维偏离预算与监控。
- APP-06：待修复，输入新鲜度、有限值、时钟/定位复位。
- APP-07：待修复，外部模式接管让步。
- APP-08：待修复，规划、导出及模式服务不阻塞发布。
- APP-09：待修复，三维停稳后完成返航。
